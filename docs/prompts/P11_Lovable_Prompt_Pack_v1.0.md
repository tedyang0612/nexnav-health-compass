3. 用藥與保健品問題：藥師
4. 一般運動安排與體能訓練：具相關資格的運動教練

第 4 項附註：若有疼痛、受傷或復健需求，建議先尋求醫療專業評估。
第 5 項附註：若疼痛持續、加重、曾經受傷或已影響日常活動，建議先接受醫療專業評估。
